## 🔥 Warm-up: The owner's first coffee
You own the store. It's 8 a.m. What 5 things do you want to know first?

## 💡 Big idea
- ⚡ **Event trigger** — starts when something happens
- ⏰ **Time trigger** — starts at a set time

**Let the script count, let the AI write.** Numbers come from the script. The friendly words come from Claude.

```try
Write a Google Apps Script function "dailySummary" for my sheets "Orders" (Date, Name, Product, Quantity, Price) and "Practice Inbox" (Message, Category, Urgent, Draft reply, Approve?, Sent). Count yesterday's orders and total money in the script. List urgent messages and unapproved drafts. Then call the Claude API (key from Script Properties) to write a friendly 3-sentence summary and up to 3 to-dos, using ONLY those numbers. Email it to my test address. Explain each part simply.
```

## 🛠️ Your build
- [ ] Get the script from Claude
- [ ] Run it by hand first and read the email
- [ ] Check every number against the sheet
- [ ] Add a time trigger: every day, 8 to 9 a.m.
- [ ] Make it yours: brand name, emoji, your 5 must-knows

## ⚔️ Challenge: Catch the Wrong Number
Change something in the sheet. Run the summary. Did it notice?

```group
Try to fool someone else's summary!
```

```solo
**You vs. your teacher.** Secretly change 2 things in each other's sheets. Spot them from the email!
```

## 🎟️ Exit ticket
1. What's the difference between an event trigger and a time trigger?
2. Why should the script do the counting, not the AI?
3. How do you turn a trigger off?

## 🛡️ Stay safe
Timer helpers can flood an inbox if something breaks. Know where the off switch is!
