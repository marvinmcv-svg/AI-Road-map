## 🔥 Warm-up: Would you send it?

## 💡 Big idea: the Risk Grid
| | Rare | A lot |
|---|---|---|
| **Low risk** | 🤖 robot | 🤖 robot + spot-check |
| **High risk** | 🧑 human | 🤖 drafts + 🧑 approves every one |

**Approval loop:** AI drafts → you read → ✅ approve / ✏️ edit / ❌ reject → only ✅ is sent → record when.

**Good checker habits:** read the whole draft · check facts · check the tone · never approve without reading.

```try

```
