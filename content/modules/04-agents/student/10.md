## 🛠️ Your build: Demo-ready checklist
- [ ] Workflow map is up to date
- [ ] Helper runs from start to finish by itself
- [ ] AI step uses Store Facts and a fixed format
- [ ] Human check before anything risky is sent
- [ ] API key is in Script Properties, not in the code
- [ ] Attacks tested, guardrails added, limits and an off switch
- [ ] Scorecard: baseline vs. final, plus time saved
- [ ] Triggers send to test addresses, practice data only
- [ ] Score yourself with the rubric and fix your lowest row
