## 🔥 Warm-up: Do it by hand
Answer 3 test orders by hand. Time it. Now imagine 50 a day!

## 💡 Big idea: trigger → action
**Form sent** (trigger) → **thank-you email** (action 1) → **Status = New** (action 2)

How to build it:
1. Sheet → **Extensions → Apps Script**
2. Ask Claude to write the script and explain it simply
3. Paste, save, add the **On form submit** trigger
4. Read the permissions, then say yes
5. Place a test order and check the log

```try
Write a Google Apps Script for a Google Sheet that gets answers from a Google Form. When a new form answer comes in: (1) send a short thank-you email to the email in the "Email" column, using the "Name" and "Product" columns, from my brand "Sip Squad"; (2) write "New" in a column called "Status". Explain each part in plain, simple words. Tell me exactly how to set the "On form submit" trigger.
```

## 🛠️ Your build
