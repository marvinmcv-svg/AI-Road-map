## 🔥 Warm-up: Robot meets brain
Your Claude Project is smart. Your automation runs by itself. What if they worked together? Draw it!

## 💡 Big idea: the AI step
**Sheet row → script sends a request to the Claude API → Claude sends back Category | Urgent | Draft → script writes it in the sheet.**

💳 **How you pay:** the API uses prepaid **credits** in the **Claude Console**. Each message costs a tiny bit.

🔑 **Key and money rules**
- Get the key in the **Claude Console**
- Set a low **monthly spending limit** first
- Save the key in **Script Properties** as `ANTHROPIC_API_KEY`
- Never put it in code, a chat, a doc or a screenshot
- If it leaks: delete it and make a new one

🔒 **Privacy:** send only what the job needs. In class, use **made-up messages only**.

```try
Write a Google Apps Script for my "Practice Inbox" sheet (columns: Message, Category, Urgent, Draft reply). Add a menu "Helper → Sort new messages". For every row where Category is empty, call the Claude API (Messages API) with my instructions plus the message, and write back the Category, Urgent and Draft reply. Read the API key from Script Properties (ANTHROPIC_API_KEY). Use the model claude-opus-5-5. Stop after 20 rows per run and wait 2 seconds between calls. Explain each part in plain words.
```
