## 🔥 Warm-up: Robot meets brain
Your Gem is smart. Your automation runs by itself. What if they worked together? Draw it!

## 💡 Big idea: the AI step
**Sheet row → script sends a request to the Gemini API → Gemini sends back Category | Urgent | Draft → script writes it in the sheet.**

🔑 **API key rules**
- Get it in **Google AI Studio**
- Save it in **Script Properties** as `GEMINI_API_KEY`
- Never put it in code, a chat, a doc or a screenshot
- If it leaks: delete it and make a new one

⚠️ **Free tier:** Google may use what you send to improve its products. Use **made-up messages only**.

```try
Write a Google Apps Script for my "Practice Inbox" sheet (columns: Message, Category, Urgent, Draft reply). Add a menu "Helper → Sort new messages". For every row where Category is empty, call the Gemini API with my instructions plus the message, and write back the Category, Urgent and Draft reply. Read the API key from Script Properties (GEMINI_API_KEY). Use a current Gemini Flash model. Wait 2 seconds between calls. Explain each part in plain words.
```
