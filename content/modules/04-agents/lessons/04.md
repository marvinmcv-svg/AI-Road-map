## Lesson objectives
By the end, the student can…
- Explain **trigger** and **action** in a real automation.
- Use Gemini to write an Apps Script that runs when a form is sent.
- Give the script permission safely, test it and read its log.

## Words for today
- **Apps Script** — Google's way to write small programs that work with Sheets, Forms and Gmail.
- **Script** — a small program: a list of steps for the computer.
- **Action** — what the automation does when the trigger happens.
- **Permission** — saying "yes" to let a script use your email or files.
- **Log** — a list of what the script did, so you can check it.
- **Test data** — made-up info you use to check that it works.

## 1. Warm-up — Do it by hand (10 min · 1-on-1: 5 min)
Fill in the order form 3 times with test info. For each "order", write a thank-you email by hand and add "New" to the sheet. Time it. Now imagine 50 orders a day!

```solo
The student plays the store owner; you place 3 quick test orders. Time how long the replies take. Write the number down.
```

## 2. Mini-lesson — Trigger → action (12 min · 1-on-1: 8 min)
Show **Visual 1**: **Form sent (trigger) → send thank-you email (action 1) → set Status to "New" (action 2).**

How we'll build it:
1. Open the answers sheet → **Extensions → Apps Script**.
2. Ask Gemini to write the script (prompt below). Ask it to **explain each part in plain words**.
3. Paste it in, save, and set a trigger: **Triggers → Add trigger → On form submit**.
4. Say "yes" to the permissions, after reading what it asks for.
5. Place a test order. Check the email and the sheet. Read the log.

```
Write a Google Apps Script for a Google Sheet that gets answers from a Google Form.
When a new form answer comes in: (1) send a short thank-you email to the email in the "Email" column, using the "Name" and "Product" columns, from my brand "Sip Squad"; (2) write "New" in a column called "Status".
Explain each part in plain, simple words. Tell me exactly how to set the "On form submit" trigger.
```

**Permissions:** the script asks to send email as you and edit your sheet. That's what we want. If a script ever asks for more than it needs, stop and ask why.

## 3. Hands-on build — Automate your thank-you (43 min · 1-on-1: 30 min)
1. Use the practice copy of your form and sheet.
2. Get the script from Gemini. Read what Gemini says each part does. Change the email words to match your brand.
3. Paste, save, add the On form submit trigger, accept permissions.
4. Place 3 test orders. Check: email arrives? Status says "New"?
5. If it breaks, copy the error message to Gemini: "This error happened: [paste]. What's wrong and how do I fix it?"

**Checkpoint 1 (+20 XP):** script runs and sends one thank-you email.
**Checkpoint 2 (+20 XP):** 3 test orders work by themselves, and the student can explain each part of the script.

```group
Pairs place test orders on each other's forms.
```

```solo
You place the test orders from your phone while the student watches the sheet and their inbox. Every time something doesn't happen, they read the log and ask Gemini, not you.
```

> 🛡️ **Safety moment:** test on a COPY with test emails you own. Never send test emails to real customers. Turn off the trigger (Triggers → delete) if anything goes wrong.

## 4. Game / challenge — Break the Robot (10 min · 1-on-1: 7 min)
Try weird orders: no name, a strange email, 999 bottles, emoji in the name. What breaks? Fix one problem.

```group
Most bugs found and fixed: +15 XP. Everyone: +5.
```

```solo
**Student vs. Bolt.** You try to break their automation with 3 weird orders; they try to break yours. Each bug found and fixed = 1 point. +15 XP for playing, +5 for the win.
```

## 5. Share-out — Hands off! (10 min · 1-on-1: 5 min)
Place an order live while the maker keeps their hands off the keyboard. The email arrives by itself!

```solo
Compare with the warm-up time. How many minutes would this save per week?
```

## 6. Exit ticket (5 min)
1. What's the trigger and what are the actions in your automation?
2. What's a log for?
3. What should you check before saying "yes" to permissions?

```solo
Ask out loud. Make sure the trigger is only on the practice copy for now.
```

## Differentiation
- **Extra help:** one action only (the thank-you email). Use the exact prompt above.
- **Extra challenge:** add a third action: email the store owner a one-line "New order!" note. Or send a different email for each product.
- **1-on-1 tip:** ask the student to explain the script to you one line at a time, like a tour guide. If they can't, ask Gemini to explain that line more simply.
