## Lesson objectives
By the end, the student can…
- Explain the difference between an **event trigger** and a **time trigger**.
- Build a daily summary that uses numbers from the sheet and a short AI-written summary.
- Check that the summary matches the real data.

## Words for today
- **Event trigger** — starts when something happens (a form is sent).
- **Time trigger** — starts at a set time (every day at 8 a.m.).
- **Summary** — a short version of the important stuff.
- **To-do** — a job that still needs doing.
- **Dashboard** — one place that shows the important numbers at a glance.

## 1. Warm-up — The owner's first coffee (10 min · 1-on-1: 5 min)
```teacher
Imagine a helper that tells you what matters every morning. Today you build it. It runs on a timer, all by itself. What would you want to know?
```

Imagine you own the store. It's 8 a.m. What 5 things do you want to know before anything else? Write them down.

```solo
You both write a list, then merge them into the "perfect morning summary" plan.
```

## 2. Mini-lesson — Helpers on a timer (12 min · 1-on-1: 8 min)
Show **Visual 1**: **8:00 a.m. (time trigger) → script reads sheets → counts orders and urgent messages → asks Claude for a 3-sentence summary + to-dos → emails it to the owner.**

**Let the computer count, let the AI write.** Numbers (how many orders, total money) should come from the script's own math, not the AI. AI is great at writing the friendly summary, but it can get numbers wrong.

**A great summary** (**Visual 2**):
- 📦 Orders yesterday: 7 (total $140)
- 🔥 Urgent messages: 2 (1 late order, 1 broken bottle)
- ✅ To-do: approve 5 drafts, restock teal
- 💬 One-line mood: "Good day! Teal is the top seller."

## 3. Hands-on build — Build the morning helper (43 min · 1-on-1: 30 min)
1. Ask Claude for the script:
```
Write a Google Apps Script function "dailySummary" for my sheets "Orders" (columns: Date, Name, Product, Quantity, Price) and "Practice Inbox" (columns: Message, Category, Urgent, Draft reply, Approve?, Sent).
Count yesterday's orders and total money in the script itself. List urgent messages and unapproved drafts. Then call the Claude API (key from Script Properties, model claude-opus-5-5) to write a friendly 3-sentence summary and up to 3 to-dos, using ONLY those numbers. Email it to [your test email] with the subject "Good morning, Sip Squad!". Explain each part simply.
```
2. Run it by hand first. Read the email. Is every number right?
3. Add a **time trigger**: Triggers → Add trigger → Time-driven → Day timer → 8 a.m. to 9 a.m.
4. Make it yours: brand name, emoji, the things YOU wanted in the warm-up.

**Checkpoint 1 (+20 XP):** summary email arrives with correct numbers.
**Checkpoint 2 (+20 XP):** daily time trigger set, and the summary includes to-dos.

```group
Pairs check each other's summary numbers against the sheet.
```

```solo
After the first run, the student counts the orders by hand and compares. If the numbers are wrong, ask: "Who did the counting, the script or the AI?"
```

> 🛡️ **Inbox moment:** helpers that email on a timer can fill an inbox fast if something breaks. Know how to turn a trigger off (Triggers → ⋮ → Delete).

## 4. Game / challenge — Catch the Wrong Number (10 min · 1-on-1: 7 min)
Change one thing in the sheet (add an order, mark a message urgent). Run the summary again. Did it notice? Then swap sheets and try to fool someone else's summary.

```group
Each summary that catches all changes: +15 XP. Everyone: +5.
```

```solo
**Student vs. Bolt.** You secretly change 2 things in their sheet; they run the summary and find what changed from the email alone. Then swap. +15 XP for playing, +5 for spotting both.
```

## 5. Share-out — 30-second read (10 min · 1-on-1: 5 min)
Read your summary out loud. Can a busy owner act on it in 30 seconds?

```solo
The student reads it to you like a radio news update. Cut anything that isn't useful.
```

## 6. Exit ticket (5 min)
1. What's the difference between an event trigger and a time trigger?
2. Why should the script do the counting, not the AI?
3. How do you turn a trigger off?

```solo
Ask out loud. Make sure the trigger sends only to a test address.
```

## Differentiation
- **Extra help:** summary with numbers only (no AI step). Add the AI part later.
- **Extra challenge:** a weekly report every Monday with a simple chart in the sheet and a "best seller" line.
- **1-on-1 tip:** set the trigger to send the summary to the student's phone during the next lesson. Getting a "Good morning" from their own robot is a big moment.
