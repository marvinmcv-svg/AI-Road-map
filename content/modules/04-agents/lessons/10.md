## Lesson objectives
By the end, the student can…
- Demo a working AI helper from trigger to result, live.
- Explain where the human check is, how it stays safe, and how well it works (scorecard).
- Score their helper with the rubric and fix the weakest part.

## Words for today
All the Module 4 words. Most of all: workflow, trigger, AI agent, Gem, API key, human in the loop, prompt injection, test set.

## 2. Mini-lesson — What "Pro" looks like (5 min)
Go through the rubric's **4 · Pro** column, one row at a time. Show a strong example (your demo helper).

## 3. Hands-on build — Demo-ready checklist (35 min · 1-on-1: 25 min)
- [ ] Workflow map is up to date (trigger → steps → tools → check)
- [ ] The helper runs from start to finish without help
- [ ] AI step uses Store Facts and a fixed format
- [ ] Human check before anything risky is sent
- [ ] API key is in Script Properties, not in the code
- [ ] Safety: attacks tested, guardrails added, limits and an off switch
- [ ] Scorecard: baseline vs. final, plus time saved
- [ ] All triggers send to test addresses, with practice data only

Score yourself with the rubric. Write one sentence of proof for each row. Last 10 minutes: fix the lowest row.
**Checkpoint (+20 XP):** checklist done + self-score written.

```solo
Let the student self-score first, then compare with your score. Where you disagree, run that part again together.
```

## 4. Game / challenge — Demo Day (30 min · 1-on-1: 15 min)
A 4-minute demo:
1. **The problem:** "Every day, ___ took me ___ minutes."
2. **The map:** show the workflow map.
3. **Live run:** trigger it (place a test order, add a test message, or run the summary).
4. **The human check:** approve one draft live.
5. **Safety:** try one attack live and show it being blocked.
6. **The numbers:** scorecard + time saved.
7. **Honest limits:** "It still can't ___, so a human does that."

Guests ask one question each and fill in a ⭐ strength and ❓ question card.

**Boss XP:** rubric total (4 rows × 1 to 4 points) × 6 = up to 96. Round up to 100 for a perfect score. **⚙️ Flow Builder** badge for 3 or more on every row.

```group
Awards: "Most Time Saved", "Toughest to Trick", "Best Human Check" (+15 house XP each).
```

```solo
**Shark tank.** Guests are "business owners" deciding whether to use the helper. After the demo, they each say "I'd use it" or "Not yet", with a reason. Award "Best in Show" (+15 XP).
```

## 5. Share-out — Robot party (10 min · 1-on-1: 5 min)
Celebrate! Then tease the next quest: *"Your helpers run the store. Now build something just for YOU: your own app, on your phone."*

```solo
Ask the student which helper they'd keep using in real life. Help them turn off any practice triggers they don't need.
```

## 6. Exit ticket (5 min)
1. What part of your helper are you most proud of? Why?
2. What would you never let your helper do alone?
3. What would you build next with one more lesson?

```solo
Ask out loud. Save the answers for a progress note.
```

## Differentiation
- **Extra help:** a helper with the automation + human check (no AI step) can still earn level 3 if it's safe, tested and measured.
- **Extra challenge:** connect 2 helpers so one's output starts the other (sorted message → draft → approval → daily summary includes it). That's a multi-step agent!
- **1-on-1 tip:** a guest who runs a real small business can give the most useful feedback of the year. Worth asking around!
