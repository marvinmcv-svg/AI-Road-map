## Lesson objectives
By the end, the student can…
- Explain what an **API** and an **API key** are, and how API use is paid for.
- Keep an API key secret and set a spending limit.
- Build a script that sends messages to Claude and writes back a category and a draft reply.

## Words for today
- **API** — a way for one program to talk to another. Your script talks to Claude through the Claude API.
- **API key** — a secret password that lets your script use the API, and charges your account. Keep it secret!
- **Credits** — money you add to your Claude Console account ahead of time. Each request uses a tiny bit.
- **Spending limit** — the most your account can spend in a month. A safety net.
- **Request / response** — what your script sends (instructions + message) and what comes back.
- **Draft** — a first version a human will check before it's sent.

## 2. Mini-lesson — How the AI step works (15 min · 1-on-1: 10 min)
Show **Visual 1**: **New row in sheet → script sends a request to the Claude API (instructions + message) → Claude sends back "Category | Urgent | Draft reply" → script writes it into the sheet.**

**How you pay:** the Claude app (claude.ai) and the Claude API are paid for in two different places. The API uses prepaid **credits** in the **Claude Console**. Each message costs a tiny bit. Sorting 20 short practice messages costs about a few cents with Claude Haiku 5.5, more with Claude Opus 5.5. Check Console → Usage after each run.

**Key and money rules** (**Visual 2**):
1. Get the key in the **Claude Console → API keys**.
2. Set a low **monthly spending limit** in the Console before you run anything.
3. Save the key in Apps Script **Project Settings → Script Properties** (name: `ANTHROPIC_API_KEY`). Never paste it into the code, a chat, a doc or a screenshot.
4. If it ever leaks, delete it in the Console and make a new one.

**Privacy rule:** Anthropic says it doesn't use what you send through the API to train its models by default. Still, a helper should only get the info the job needs. In class we use **made-up practice messages only**.

**Picking a model:** Claude Opus 5.5 (`claude-opus-5-5`) gives the best answers. Claude Haiku 5.5 (`claude-haiku-5-5`) is much faster and cheaper, and is often good enough for sorting. Try both in lesson 9!

**The prompt** to Claude (in the chat, to get the script):
```
Write a Google Apps Script for my "Practice Inbox" sheet (columns: Message, Category, Urgent, Draft reply).
Add a custom menu "Helper → Sort new messages". For every row where Category is empty, call the Claude API (Messages API) with my instructions below plus the message, and write back the Category, Urgent and Draft reply.
Read the API key from Script Properties (ANTHROPIC_API_KEY). Use the model claude-opus-5-5. Stop after 20 rows per run and wait 2 seconds between calls. Show a clear message if the API returns an error.
Ask Claude to answer in this exact format: Category: ___ | Urgent: yes/no | Draft: ___
My instructions: [paste your sorting instructions and Store Facts]
Explain each part in plain words.
```

## 3. Hands-on build — Sort the inbox (40 min · 1-on-1: 28 min)
1. In the Claude Console: add a small amount of credit, set a spending limit, make an API key.
2. Save the key in Script Properties.
3. Get the script from Claude, read what each part does, paste it, save.
4. Reload the sheet. Click **Helper → Sort new messages**. Accept permissions.
5. Watch the Category, Urgent and Draft reply columns fill in.
6. Compare categories with your answer key. Read 5 drafts: are they true to your Store Facts?
7. Check the cost in Console → Usage. If there's an error, paste it into Claude (never the key!) and fix it.

**Checkpoint 1 (+20 XP):** key stored safely in Script Properties, spending limit set, the menu runs.
**Checkpoint 2 (+20 XP):** all 20 practice messages sorted with drafts, accuracy and cost written down.

```group
Pairs check each other's code for a pasted key before running anything.
```

```solo
Before the first run, ask the student to show you where the key is stored, and to search the code for it. If it's in the code, move it. Then check the spending limit together and let them run it.
```

> 🛡️ **Secret key moment:** an API key is like a credit card for your Claude Console account. Anyone who has it can spend your credits. Treat it like a password.

## 4. Game / challenge — AI vs. Answer Key (10 min · 1-on-1: 7 min)
Who sorted better, you or the AI? Count your own mistakes vs. the AI's. Read 3 drafts aloud. Would you send them as-is?

```group
Best accuracy + best draft (class vote): +15 XP. Everyone: +5.
```

```solo
**Student vs. Bolt.** You each pick the 3 worst drafts in the other's sheet and explain why. Then each fixes one instruction to improve them. +15 XP for playing, +5 for a better second run.
```

## 5. Share-out — One click, whole inbox (10 min · 1-on-1: 5 min)
Clear the columns and run it live. 20 messages sorted while you watch!

```solo
Time the run and check the cost. Compare with how long sorting 20 messages by hand would take.
```

## 6. Exit ticket (5 min)
1. What is an API? What is an API key?
2. Where do you keep the key, and where do you never put it?
3. Why set a spending limit before the first run?


## Differentiation
- **Extra help:** only the Category column (no drafts). Use the exact prompt and fill in the instructions together.
- **Extra challenge:** add a "Confidence" column (high/medium/low) and make the script skip drafting when confidence is low, marking the row "Ask a human". Or log the cost of each run in a new tab.
- **1-on-1 tip:** this is the hardest technical lesson. Go slow, celebrate each green step, and let the student read every error message out loud before asking Claude.
