## Lesson objectives
By the end, the student can…
- Explain what an **API** and an **API key** are.
- Keep an API key secret (never in the code, never shared).
- Build a script that sends messages to Gemini and writes back a category and a draft reply.

## Words for today
- **API** — a way for one program to talk to another. Your script talks to Gemini through its API.
- **API key** — a secret password that lets your script use the API. Keep it secret!
- **Request** — what your script sends (the instructions + the message).
- **Response** — what comes back (the category and the draft).
- **Draft** — a first version a human will check before it's sent.
- **Rate limit** — how many requests you can send in a minute or a day.

```solo
The student draws "automation + AI" in 3 boxes. Compare with Visual 1.
```

## 2. Mini-lesson — How the AI step works (15 min · 1-on-1: 10 min)
Show **Visual 1**: **New row in sheet → script sends request to Gemini API (instructions + message) → Gemini sends back "Category | Urgent | Draft reply" → script writes it into the sheet.**

**API key rules** (**Visual 2**):
1. Get it from **Google AI Studio → Get API key**.
2. Save it in Apps Script **Project Settings → Script Properties** (name: `GEMINI_API_KEY`). Never paste it into the code, a chat, a doc or a screenshot.
3. If it ever leaks, delete it in AI Studio and make a new one.

**Free tier rule:** on the free tier, Google may use what you send to improve its products, and people may read it. So we use **made-up practice messages only**. A real store would pay for the paid tier, where your data isn't used that way, and still send only what's needed.

**The prompt** to Gemini (in the chat, to get the script):
```
Write a Google Apps Script for my "Practice Inbox" sheet (columns: Message, Category, Urgent, Draft reply).
Add a custom menu "Helper → Sort new messages". For every row where Category is empty, call the Gemini API with my instructions below plus the message, and write back the Category, Urgent and Draft reply.
Read the API key from Script Properties (GEMINI_API_KEY). Use a current Gemini Flash model. Wait 2 seconds between calls.
Ask Gemini to answer in this exact format: Category: ___ | Urgent: yes/no | Draft: ___
My instructions: [paste your sorting instructions and Store Facts]
Explain each part in plain words.
```

## 3. Hands-on build — Sort the inbox (40 min · 1-on-1: 28 min)
1. Get an API key in AI Studio. Save it in Script Properties.
2. Get the script from Gemini, read what each part does, paste it, save.
3. Reload the sheet. Click **Helper → Sort new messages**. Accept permissions.
4. Watch the Category, Urgent and Draft reply columns fill in.
5. Compare categories with your answer key. Read 5 drafts: are they true to your Store Facts?
6. If there's an error, paste it into Gemini (never the key!) and fix it.

**Checkpoint 1 (+20 XP):** key stored safely in Script Properties; the menu runs.
**Checkpoint 2 (+20 XP):** all 20 practice messages sorted with drafts, accuracy written down.

```group
Pairs check each other's code for a pasted key before running anything.
```

```solo
Before the first run, ask the student to show you where the key is stored, and to search the code for it. If it's in the code, move it. Then let them run it.
```

> 🛡️ **Secret key moment:** an API key is like a credit card for your Google AI account. Anyone who has it can use your account. Treat it like a password.

## 4. Game / challenge — AI vs. Answer Key (10 min · 1-on-1: 7 min)
Who sorted better, you or the AI? Count your own mistakes vs. the AI's. Read 3 drafts aloud. Would you send them as-is?

```group
Best accuracy + best draft (class vote): +15 XP. Everyone: +5.
```

```solo
**Student vs. Bolt.** You each pick the 3 worst drafts in the other's sheet and explain why. Then each fixes one instruction to improve them. +15 XP for playing, +5 for a better second run.
```

## 5. Share-out — One click, whole inbox (10 min · 1-on-1: 5 min)
Clear the columns and run it live. 20 messages sorted while you watch!

```solo
Time the run. Compare with how long sorting 20 messages by hand would take.
```

## 6. Exit ticket (5 min)
1. What is an API? What is an API key?
2. Where do you keep the key, and where do you never put it?
3. Why do we use only made-up messages on the free tier?

```solo
Ask out loud. Double-check the key isn't in the code before ending the lesson.
```

## Differentiation
- **Extra help:** only the Category column (no drafts). Use the exact prompt and fill in the instructions together.
- **Extra challenge:** add a "Confidence" column (high/medium/low) and make the script skip drafting when confidence is low, marking the row "Ask a human".
- **1-on-1 tip:** this is the hardest technical lesson. Go slow, celebrate each green step, and let the student read every error message out loud before asking Gemini.
