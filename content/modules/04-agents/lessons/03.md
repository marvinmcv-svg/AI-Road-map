## Lesson objectives
By the end, the student can…
- Explain why AI answers can change each time, and 3 ways to make them steadier.
- Give a helper **examples** and a **fixed format** for its answers.
- Make the helper **sort** 20 messages into categories and score it against an answer key.

## Words for today
- **Reliable** — works the same way, again and again.
- **Example (few-shot)** — showing the AI a few finished examples so it copies the pattern.
- **Fixed format** — the answer always comes in the same shape, like `Category: ___ | Urgent: yes/no`.
- **Category** — a group or box something gets sorted into.
- **Answer key** — the right answers, written by a person, used to check the AI.
- **Accuracy** — how many it got right, out of all of them (like 17 out of 20).

## 1. Warm-up — The wobble test (10 min · 1-on-1: 5 min)
```teacher
A helper is only useful if it gives the same good answer every time. Today you make it steady. Let's test how steady Claude is right now.
```

Ask Claude 5 times (new chat each time): "Is this message a question, a complaint or spam? 'Hi, my bottle came with a scratch, not a big deal but wanted you to know.'" Do you get the same answer every time?

```solo
Run it together. Count the different answers. Ask: "If a robot sorted your email like this, would you trust it?"
```

## 2. Mini-lesson — 3 reliability tricks (12 min · 1-on-1: 8 min)
Show **Visual 1**:
1. **Clear categories with meanings.** Not just "complaint", but "Order problem = something is wrong with an order they already made."
2. **Examples.** Show 3 to 5 messages with the right answer.
3. **Fixed format.** "Answer ONLY in this format: `Category: ___ | Urgent: yes/no | Why: (5 words)`"

*Example to add to the instructions:*
```
Message: "Where is my order? It's been 2 weeks!"
Category: Order problem | Urgent: yes | Why: late order, upset customer
```

**Why it matters:** in the next lessons, a computer program will read the helper's answers. Programs need the same shape every time.

## 3. Hands-on build — Teach your helper to sort (38 min · 1-on-1: 27 min)
1. Pick 4 or 5 categories for your store (like: Product question · Order problem · Compliment · Wholesale · Spam). Write a one-line meaning for each.
2. Add a new section to your Project's instructions: "Sorting job", with the categories, 3 examples and the fixed format.
3. Paste the 20 practice messages, one at a time or all at once. Copy the answers into the Practice Inbox sheet.
4. Score it against the answer key. Write the **accuracy** (like 16/20).
5. Look at the misses. Fix a category meaning or add an example. Score again.

**Checkpoint 1 (+20 XP):** sorting instructions with categories, examples and a fixed format.
**Checkpoint 2 (+20 XP):** scored twice, with the second score the same or higher.

```group
Pairs check each other's misses: is the AI wrong, or is the answer key unclear?
```

```solo
You write the answer key with the student, out loud, before the AI runs. Spots where you two don't agree are great: they show which categories need a clearer meaning.
```

> 🛡️ **Practice data moment:** all 20 messages are made up. When we test AI helpers, we never paste in real people's messages.

## 4. Game / challenge — Edge Case Battle (15 min · 1-on-1: 10 min)
Write messages that are hard to sort ("I love the bottle but it leaked, can I buy 50 for my team?"). Does the helper handle it? Should it pick one category or flag it for a human?

```group
Houses swap 3 edge cases. Helpers that handle them well (or flag them) score. Most points: +15 XP. Everyone: +5.
```

```solo
**Student vs. Bolt.** You each write 3 sneaky messages for the other's helper. Score how many it handles well. +15 XP for playing, +5 for the win.
```

## 5. Share-out — Score board (10 min · 1-on-1: 5 min)
Share your first and second accuracy. What change helped the most?

```solo
The student explains which fix raised the score. Add the scores to their Prompt Log.
```

## 6. Exit ticket (5 min)
1. Name the 3 reliability tricks.
2. What is accuracy?
3. Why do programs need a fixed format?

```solo
Ask out loud. Keep the Practice Inbox. You'll use it in lessons 5 and 9.
```

## Differentiation
- **Extra help:** use 3 categories and 10 practice messages.
- **Extra challenge:** add an "Urgent" score from 1 to 3 and a short suggested next step for each message, still in a fixed format.
- **1-on-1 tip:** turn scoring into a game: each of you guesses the accuracy before you count.
