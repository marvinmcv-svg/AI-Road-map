## Lesson objectives
By the end, the student can…
- Say what happens when you type a web address and a page shows up.
- Name 3 things a web page is made of: **HTML** (the parts), **CSS** (the look) and **JavaScript** (the actions).
- Build a one-page site with Claude and publish it with a link.

## Words for today
- **Website** — a set of pages anyone can open on the internet.
- **Web address (URL)** — the name you type to find a page, like *sipsquad.example*.
- **Browser** — the app that shows web pages (Chrome, Safari, Edge).
- **HTML** — the code that says what's on the page: titles, words, pictures, buttons.
- **CSS** — the code that says how it looks: colors, fonts, spacing.
- **JavaScript** — the code that makes things happen when you click.
- **Hosting** — a computer that keeps your page online, so others can see it.

## 1. Warm-up — Peek behind the page (10 min · 1-on-1: 5 min)
Open a simple website. Right-click → **View page source**. Wow, it's all words and symbols! Find the page title in the code. Change the text size with Ctrl and + and see the page move around.

```teacher
Your company has a look and a launch video. But where do people go when they want to buy? They go to a website. For the next 11 lessons, you'll build one, with a real online store.
```

```group
Pairs race to find the page title in the code of the same website.
```

```solo
The student finds the page title in the code. Then they pick a website they use every day, and you both guess what parts are HTML, CSS and JavaScript.
```

## 2. Mini-lesson — What happens when you visit a page (15 min · 1-on-1: 10 min)
Show **Visual 1** and tell it like a story:
1. You type a **web address** in your **browser**.
2. The browser asks the internet: "Which computer has this page?"
3. That computer (the **host**) sends back the files.
4. Your browser reads the files and draws the page.

A page is made of 3 kinds of code (**Visual 2**):
| Code | Job | Like a house… |
|---|---|---|
| **HTML** | What's on the page | The walls and rooms |
| **CSS** | How it looks | The paint and furniture |
| **JavaScript** | What happens when you click | The lights and doorbell |

**Good news:** you don't have to write the code yourself. **Claude** writes it from your words and shows it as an **artifact**: a live preview right next to the chat. You'll be the boss who says what you want, checks it and fixes it.

**The Web Prompt Recipe:**
1. **What it is:** "Make a one-page website for…"
2. **Who it's for:** the buyers
3. **Sections, in order:** top part, 3 reasons, a call to action…
4. **Look:** brand colors (with codes), fonts, mood
5. **Rules:** works on phones, big buttons, short words

## 3. Hands-on build — First page with Claude (35 min · 1-on-1: 25 min)
1. Open **Claude**. Paste a Web Prompt Recipe prompt for your company (see the example in the student mission). Claude builds the page as an artifact.
2. Look at the **artifact preview**. Click around.
3. Ask for 3 changes, one at a time: a color, a section, a button. ("Make the top part brand teal #1CB0F6." "Add 3 reasons to buy with icons.")
4. Switch the artifact to the **Code** view. Find one HTML part, one CSS part, and one JavaScript part (if there is any).
5. **Publish** the artifact to get a public link. Open it on a phone.

**Checkpoint 1 (+20 XP):** page made, with 3 changes written in the Prompt Log.
**Checkpoint 2 (+20 XP):** shared link opens on a phone.

```group
Everyone builds their own page. Walk around and ask: "What's the first thing a visitor sees?"
```

```solo
The student types; you play "visitor" and click everything. Say out loud what confuses you. That becomes their next change.
```

> 🛡️ **Public link moment:** a public link means anyone with it can see your page. Don't put your real address, phone number or anything private on it.

## 4. Game / challenge — Name That Part (15 min · 1-on-1: 10 min)
Show 6 bits of a web page (a heading, a color, a button that opens a menu, a picture, a font, a pop-up). Is it **HTML**, **CSS** or **JavaScript**?

```group
Houses answer on whiteboards. Most right: +15 XP. Everyone: +5.
```

```solo
**Student vs. Bolt.** Take turns pointing at things on a real website. The other person says HTML, CSS or JavaScript in 5 seconds. +15 XP for playing, +5 for 5 or more right.
```

## 5. Share-out — Link swap (10 min · 1-on-1: 5 min)
Open the page on a phone. Feedback: *I like… / I wonder… / Try…*

```solo
Send the link to a guest (a friend or family member, if the student wants). Ask them one question: "What does this company sell?" Did they get it right?
```

## 6. Exit ticket (5 min)
1. What happens when you type a web address? Name 2 steps.
2. What are HTML, CSS and JavaScript for?
3. What's one thing you'd never put on a public page?

```solo
Ask out loud. Have the student draw Visual 1 from memory.
```

A dotted path goes through a cloud labeled "the internet" to a small server computer labeled "host" holding three file icons labeled HTML, CSS, JS. ```

**Visual 2 — HTML, CSS, JavaScript as a house.**
```prompt
A three-panel illustration, 16:9. Panel "HTML" shows the plain frame of a cartoon house with walls and rooms. Panel "CSS" shows the same house painted with colors and furniture. Panel "JAVASCRIPT" shows the house with lights turning on and a doorbell ringing. Short labels: "what's on the page", "how it looks", "what happens when you click". Flat cartoon style, bright colors.
```

**Visual 3 — The Web Prompt Recipe card.**
```prompt
A recipe card poster, 16:9, titled "WEB PROMPT RECIPE". Five ingredients with icons: "WHAT IT IS" (web page icon), "WHO IT'S FOR" (people icon), "SECTIONS IN ORDER" (stacked boxes), "LOOK" (paint palette), "RULES" (phone and checkmark). Playful flat design, bright colors, readable text.
```

## Differentiation
- **Extra help:** give the full example prompt to copy, then change just the company name and colors.
- **Extra challenge:** ask Claude to add a button that does something (a pop-up thank-you, a dark-mode switch). Find the JavaScript that makes it work.
- **1-on-1 tip:** have the student open their page on their own phone. Seeing their brand on their phone is a big "wow" moment.
