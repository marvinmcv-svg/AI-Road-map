## 🔥 Warm-up: Eyes closed
Turn on a screen reader. Close your eyes. Try to find the "Order" button using only sound!

## 💡 Big idea: Works for Everyone checklist
1. 📱 **Phone view** — nothing squished, big buttons, no sideways scrolling
2. 🖼️ **Alt text** — one short sentence about what matters in each picture
3. 🌗 **Contrast** — words stand out from the background
4. 🔠 **Headings in order** — real section titles, not just big bold words
5. 🔗 **Clear link words** — "See the colors", not "click here"
6. 🎬 **Captions** on videos

```try
Write alt text for this picture in under 15 words, for a website that sells it.
```

## 🛠️ Your build
- [ ] Fix 2 or more things in the phone view
- [ ] Add alt text to every important picture
- [ ] Check every text color in the contrast checker
- [ ] Use real headings for section titles
- [ ] Rename any "click here" link or button
- [ ] Publish again

## ⚔️ Challenge: Screen Reader Race
With a screen reader on, find the price and the order button. How fast can you do it?

```group
Test another house's site.
```

```solo
**You vs. your teacher.** Race on each other's sites. Fix what slowed your teacher down, then race again!
```

## 🎟️ Exit ticket
1. What is alt text? Write one for your hero picture.
2. Why is "click here" a bad button?
3. Name 3 things on the Works for Everyone checklist.

## 🛡️ Stay safe
Alt text must be true too. Describe what's really in the picture.
