## 🔥 Warm-up: Play the quiz
Play your teacher's "Which bottle is for you?" quiz. Try to break it!

## 💡 Big idea: the vibe coding loop
1. 💬 **Ask** — say exactly what happens on each click
2. 🖱️ **Test** — click everything, try weird things
3. 🔎 **Describe the bug** — what I did · what should happen · what really happened
4. 🔧 **Fix** — Gemini changes the code. Test again!

**Ideas:** 🧭 a product quiz · 🎨 a color chooser · 🧮 a price calculator

**Put it on your site:** copy the code from Canvas → in Sites: Insert → Embed → Embed code → paste.

```try
Make a 3-question quiz called "Which Sip bottle is for you?" for my website. Each question has 3 big answer buttons. At the end, show one of 3 bottles (Small, Classic, Big) with a short reason and an "Order this one" button. Colors teal #1CB0F6 and white, round friendly font. One HTML file, works on phones, no outside libraries.
```
