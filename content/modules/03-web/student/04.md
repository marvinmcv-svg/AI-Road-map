## 💡 Big idea: from words to a live website
1. 📁 **GitHub** — make a new, empty repo (a folder for your site)
2. 🤖 **Claude Code** — open the repo and give it your build prompt
3. 🖼️ **Add your pictures** — logo, product pictures, banner
4. 🔍 **Check and fix** — one change at a time
5. 💾 **Save** — Claude Code commits the files to the repo
6. 🚀 **Vercel** — import the repo and deploy. You get a real web address!

After that, every saved change goes live by itself.

```try
Build a one-page website for my brand "Sip Squad" as plain HTML, CSS and JavaScript (index.html, style.css and an images folder). Sections in this order: hero, 3 reasons, how it works, proof, call to action, footer, using the exact words from my copy below. Brand colors: teal #1CB0F6 and white. My logo is images/logo.png. Rules: phone first, big buttons, alt text on every picture, easy-to-read contrast. Explain what you made in simple words.
```
