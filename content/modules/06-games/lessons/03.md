## Lesson objectives
By the end, the student can…
- Name 6 classic **game types** and the core mechanics of each.
- Explain the difference between using a game type (OK) and copying a specific game (not OK).
- Build an original base version of one game type with Claude.

## Words for today
- **Game type (genre)** — a kind of game with familiar mechanics (like "endless runner").
- **Remix** — making something new from a familiar idea, with your own twist.
- **Theme** — the world and story of your game (space, ocean, kitchen).
- **Original** — made by you: your own name, characters, art and sounds.
- **Hitbox** — the invisible shape the game uses to check collisions.

## 1. Warm-up — Name that type (10 min · 1-on-1: 5 min)
```teacher
Lots of hit games are remixes of older game types. Today you build a classic type, with your own names and art. Which games feel the same?
```

Think of games you know. Which ones are "the same kind of game" with different looks? What do they have in common?

```solo
You each list 3 games and sort them into types together. Which type does the student love most?
```

## 2. Mini-lesson — 6 classic game types (15 min · 1-on-1: 10 min)
Show **Visual 1**:
| Game type | Core loop | What makes it hard |
|---|---|---|
| 🏓 Paddle-and-ball | Move paddle → bounce ball → don't miss | Ball speeds up |
| 🧱 Brick breaker | Bounce ball → break bricks → clear the level | Tricky angles, tough bricks |
| 🧩 Grid puzzle | Move or match pieces on a grid → clear lines | Time, limited moves |
| 🏃 Endless runner | Run → jump/slide → dodge → go farther | Speed goes up |
| 👻 Maze chase | Move through a maze → collect → escape chasers | Smart chasers |
| 🐍 Snake-style | Steer → eat → grow longer → don't hit yourself | Your own tail! |

**The copying rule:** game types and mechanics are free for everyone to use. A specific game's **name, characters, art, music and levels** belong to its makers. So we make **our own**: a new name, our own characters (Gemini can help), our own theme.

## 3. Hands-on build — Build the base (35 min · 1-on-1: 25 min)
1. Pick a game type and a theme (like "paddle-and-ball, but you're a whale bouncing a bubble").
2. Name your game. Check it's not the name of a real game.
3. Ask Claude:
```
Make an original browser game as an artifact. Game type: [type]. Theme: [theme]. Name: [name].
Core loop: [loop]. Controls: keyboard AND touch. Show score, lives and a "Play again" button.
Use simple original shapes and colors (no characters or art from real games).
Put the important numbers at the top so I can tune them.
```
4. Play it 5 times. Tune 2 numbers so it feels fair.
5. Write your plan for the twist (next lesson): "My twist will be ___."

**Checkpoint 1 (+20 XP):** original base game playable, with a new name and theme.
**Checkpoint 2 (+20 XP):** 2 tuning changes + a written twist idea.

```group
Pairs check each other's game: is everything original?
```

```solo
Play the base game together and brainstorm twists out loud. Wild ideas first, then pick one that fits in one lesson.
```

> 🛡️ **Copying moment:** no real game names, characters, logos, music or level layouts. Classic mechanics, your own look.

## 4. Game / challenge — Mechanic Detective (15 min · 1-on-1: 10 min)
Look at 3 short game clips or screenshots. For each, name the game type, the core loop and one mechanic.

```group
Most correct answers: +15 XP. Everyone: +5.
```

```solo
**Student vs. Bolt.** Take turns describing a game without naming it. The other person guesses the type and the core loop. +15 XP for playing, +5 for the most right guesses.
```

## 5. Share-out — Base game + twist plan (10 min · 1-on-1: 5 min)
Show your base game and read your twist plan.

```solo
Ask: "Will the twist change the core loop, or just the look?" A twist that changes the loop is the most fun.
```

## 6. Exit ticket (5 min)
1. Name 3 classic game types and their core loops.
2. What can you reuse from other games, and what can't you copy?
3. What's your twist?

```solo
Ask out loud. Save the artifact.
```

## Differentiation
- **Extra help:** start with paddle-and-ball or snake-style (the simplest), and use a ready-made theme.
- **Extra challenge:** make a 2-player version on one keyboard.
- **1-on-1 tip:** let the student pick the type they loved as a kid. Nostalgia is great fuel.
