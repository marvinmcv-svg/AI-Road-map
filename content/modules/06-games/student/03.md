## 🔥 Warm-up: Name that type
Which games you know are "the same kind of game" with different looks?

## 💡 Big idea: classic game types
| Type | Core loop |
|---|---|
| 🏓 Paddle-and-ball | move → bounce → don't miss |
| 🧱 Brick breaker | bounce → break bricks → clear the level |
| 🧩 Grid puzzle | move or match pieces → clear lines |
| 🏃 Endless runner | run → jump → dodge → go farther |
| 👻 Maze chase | move → collect → escape chasers |
| 🐍 Snake-style | steer → eat → grow → don't hit yourself |

**The copying rule:** game types are free to use. A real game's **name, characters, art, music and levels** are not. Make your own!

```try
Make an original browser game as an artifact. Game type: paddle-and-ball. Theme: a whale bouncing a bubble in the ocean. Name: Bubble Bounce. Controls: keyboard AND touch. Show score, lives and a "Play again" button. Use simple original shapes and colors. Put the important numbers at the top.
```
