## 💡 Big idea: smart, safe AI in games
**Great:** a character who reacts to how you played · hints when you're stuck · new riddles between rounds
**Risky:** AI changing the score · open chat · freezing the game while waiting

**The safe pattern:**
1. 🔑 Key only in Vercel environment variables
2. 🔢 A daily limit and short answers
3. ⏸️ Call the AI between rounds, not during action
4. 🛟 Fallback lines if it's slow or off
5. 📜 A system prompt: stay in character, kind and short

```try
Add an AI feature to my game: between levels, the gardener gives one short tip based on how the player did. Use a Vercel server function that calls the Claude API with model claude-opus-5-5, reading ANTHROPIC_API_KEY from environment variables. Keep answers under 25 words. Limit to 30 calls per player per day. If the AI is slow or off, show one of my fallback lines. Explain each part simply.
```
