## Lesson objectives
Students will be able to…
- Write a **Brand Brief** (name, audience, personality, mission).
- Name 5 logo types: **wordmark, lettermark, icon/pictorial, combination mark, emblem**.
- Design a logo that passes the **simplicity and scalability** test, with colors chosen on purpose.

## Vocabulary today
logo · wordmark · lettermark · icon · combination mark · emblem · scalability · color psychology · brand identity

## 1. Warm-up — Draw it from memory (10 min)
Quick retrieval: "Name the 4 AI edits from last lesson."
Then: "Draw a famous fast-food or tech logo from memory in 30 seconds." (Drawing only — we don't copy them into projects.) Ask: "Why could you remember it? Simple shapes, few colors, repeated everywhere." That's the lesson.

## 2. Mini-lesson — What makes a logo work (15 min)
**Visual 1 — Logo types** (all fictional examples):
| Type | What it is | Good when… |
|---|---|---|
| Wordmark | Styled name | Name is short and memorable |
| Lettermark | Initials | Name is long |
| Icon / pictorial | A symbol only | Brand is already known; app icons |
| Combination mark | Icon + name | **New brands — what we'll make** |
| Emblem | Name inside a badge/shape | Clubs, schools, food brands |

**The 4 logo rules:** Simple · Scalable (works at 16 px and on a billboard) · Memorable · Fits the brand personality.

**Color psychology (Visual 2):** blue = trust/calm, green = nature/health, yellow/orange = fun/energy, red = excitement/urgency, purple = creative/magic, black = premium. It's culture-dependent — a guide, not a law.

**AI tip:** AI is great at *ideas* for logos, but often weak at clean text and perfect symmetry. Generate the **icon** with AI → set the **name in Canva with a real font**.

## 3. Hands-on build — Brand Brief → Logo (40 min)
**Part A — Brand Brief (10 min):**
| Brand name | |
|---|---|
| Product/service | |
| Customers (who? age? what do they care about?) | |
| 3 personality words | e.g. playful, eco, bold |
| Mission in one sentence | We help ___ to ___ by ___. |
| Colors I'm considering and why | |

**Checkpoint 1 (+20 XP):** brief complete.

**Part B — Ideate (15 min):** generate 6 icon ideas using prompts like:
*"Minimal flat vector logo icon of a water drop shaped like a leaf, 2 colors (teal and lime), thick rounded lines, centered on white, no text, simple enough to work as an app icon, 1:1."*
Pick the best 2 and iterate once each ("simplify", "thicker lines", "only 2 colors").

**Part C — Build the combination mark (15 min):** in Canva, place the icon + brand name in a chosen font. Make 3 versions: horizontal, stacked, icon-only. Save the colors with hex codes in the Canva Brand Kit.

**Checkpoint 2 (+20 XP):** 3 logo versions saved.

> 🛡️ **Copyright moment:** Your logo must not look like a real brand (no swooshes, bitten apples, golden arches). Similar logos can get companies sued — and it's unfair to the original designers.

## 4. Game / challenge — Squint & Shrink (10 min)
Each student shrinks their logo to 16 px (favicon size) and 512 px, and squints at it from 3 meters. Partner answers: *Can you still tell what it is? Can you read the name at 64 px?* Pass both = +15 XP; anyone who fixes and re-tests = +5.

## 5. Share-out — Brief match critique (10 min)
In trios: read your 3 personality words, show the logo. Partners rate 1–5 "Does the logo feel like these words?" and suggest one change.

## 6. Exit ticket (5 min)
1. Name 3 logo types.
2. What does "scalable" mean for a logo?
3. Why did you choose your main brand color?

## Differentiation
- **Support:** choose from 3 pre-made Brand Brief examples to adapt; icon prompt template with blanks for shape + colors.
- **Extension:** create a monochrome (1-color) version and a dark-mode version; write the logo's "story" (why each shape/color) like a pro designer's case study.
