## Lesson objectives
Students will be able to…
- Keep a character consistent across images using a **character sheet**, **reference images** and a fixed **style description**.
- Recognise and fix common **AI image glitches**.
- Discuss **copyright** and fairness questions about AI art with evidence from both sides.

## Vocabulary today
reference image · style guide · consistency · artifact/glitch · copyright · training data (review)

---

## 1. Warm-up — Recall Raid (interleaved) (10 min)
1. What does a diffusion model start from?
2. Name a shot type that makes something look powerful.
3. What's the difference between inpainting and outpainting?
4. What's a combination mark?
5. Why do we add labels to diagrams ourselves?

## 2. Mini-lesson — The consistency problem (15 min)
Show the **non-example**: "a cute robot mascot" in 3 scenes → three different robots. Explain: each image starts from new random noise, so details drift.
Show the **example** with a **character sheet** (**Visual 1**):
- **Fixed description** (copy-paste the same text every time): *"Bolt, a small round teal robot with one big yellow eye, orange antenna, short stubby legs, white belly panel with a leaf logo."*
- **Fixed style line:** *"flat vector, thick outlines, soft shadows, brand colors teal/lime/white."*
- **Reference image:** use the first good image as a reference/follow-up ("same character, now skateboarding").
- **Turnaround sheet:** front / side / back views.

Quick teacher demo (18+ tool, teacher only): show how a cinematic tool like Higgsfield adds camera motion/stylised looks — "This is where images start becoming video. Next module!"

## 3. Hands-on build — Mascot & Style Guide (35 min)
1. Write the mascot's **fixed description** + **style line** (5 min).
2. Generate the mascot; pick the best → **Checkpoint 1 (+20 XP).**
3. Generate the mascot in 3 scenes using follow-ups/reference ("same character…"). Score each 1–5 for consistency.
4. Fix glitches: regenerate or use follow-up edits ("fix the hand", "remove the extra antenna").
5. Build a **brand board** page in Canva: logo, colors with hex codes, 2 fonts, mascot, 3 do's and don'ts (e.g. "Don't stretch the logo").

**Checkpoint 2 (+20 XP):** 3 consistent scenes + brand board.

## 4. Game / challenge — Glitch Hunt (15 min)
6 AI images on the screen, each with 1–3 glitches. Houses circle glitches on printouts. Categories: **hands/fingers, text, shadows/light, physics, repeated patterns, extra parts**. Most correct finds: +15 XP; all +5.

## 5. Share-out — Mini-debate: Who owns AI art? (10 min)
Four corners: *The person who wrote the prompt / The AI company / The artists whose work was in training data / Nobody*. Students stand in a corner and give one reason. Teacher shares facts: in many countries (e.g. the US Copyright Office's guidance) purely AI-generated images can't be copyrighted without meaningful human authorship; artists have sued over training on their work; rules are still being decided. Our class rule: **create originals, disclose, credit**.

## 6. Exit ticket (5 min)
1. Name 2 techniques for keeping a character consistent.
2. Name 3 common AI glitches.
3. Who do you think should own AI art? Give one reason.

## Differentiation
- **Support:** mascot description template (shape, color, eyes, accessories, logo); only 2 scenes required.
- **Extension:** create a 4-panel comic with the mascot that stays consistent; write a one-page style guide with do's and don'ts like professional brand books.
