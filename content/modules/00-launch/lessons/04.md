## Lesson objectives
Students will be able to…
- Use the full Prompt Recipe to hit a specific target output in as few iterations as possible.
- Document iterations and explain each change.
- Verify at least one AI-generated fact and flag any hallucination.
- Write a safe, original image prompt for their Guild avatar (no real faces).

## Vocabulary today
All Launch vocabulary — especially prompt, iteration, hallucination, constraint, format.

---

## 1. Warm-up — Recall Raid: Season 1 recap (10 min)
Houses answer on whiteboards (interleaved from lessons 1–3):
1. What does a model learn from?
2. Name the 5 parts of the Prompt Recipe.
3. What's a hallucination? How do you catch one?
4. Safe or Sorry: "Edit a classmate's photo into a meme without asking."
5. Why do different people get different answers from the same prompt?

+10 XP per house member for every house with 4+ correct.

## 2. Mini-lesson — Duel rules (5 min)
Show **Visual 1 (Duel arena)**. Rules:
- Each round, houses get the same **target card** (what the final output must look like).
- Houses write a prompt → teacher/house runs it → compare to target → iterate.
- **Score:** 30 pts for hitting the target · −3 pts per extra iteration after v1 · +10 if every recipe part is labelled on the score sheet · +10 for catching a hallucination in the output.
- Prompt Log is mandatory — no log, no points.

## 4. Game / challenge — THE PROMPT DUEL (35 min)
*(This lesson places the challenge before the build: the Boss comes first, the reward build second.)*

**Round 1 — Text target (10 min):** "A 4-line rhyming poem about homework, each line starting with a letter of the word 'STOP', ending with an exclamation mark."

**Round 2 — Table target (10 min):** "A table with 3 columns (Planet, Distance from Sun in million km, Fun fact) for the 4 inner planets, sorted closest first." ➜ Houses must **verify two numbers** with a trusted source (bonus +10 if they catch an error).

**Round 3 — Image target (15 min):** Show a target image (made earlier by you, e.g. *"a pixel-art red fox wearing an astronaut helmet, floating above a purple planet, square format"*). Houses write a prompt to recreate it as closely as possible. Teacher generates each house's prompt on the projector; class votes on the closest match.

Record house scores in the tracker: winner +15 XP each member, all finishing houses +5. Everyone who completes the Prompt Log earns the **⚔️ Prompt Duelist** badge.

## 3. Hands-on build — Guild Nickname & Avatar (25 min)
1. Pick a **Guild nickname** (no real name, no school, nothing personal) — e.g. "PixelPanda", "NovaByte".
2. Write an avatar prompt using the recipe. It must be a **character, animal or object — not your real face**:
   - Role/Task: "Create an avatar for a game profile…"
   - Details: favourite animal/object, 2 personal-interest props, house colour.
   - Style: pixel art / 3D clay / anime-inspired / watercolor (no copied characters or brands).
   - Format: square, centered, plain background.
3. Generate (school Gemini) **or** hand the prompt to the teacher to generate.
4. Iterate once and log what changed.

**Checkpoint (+20 XP):** nickname + avatar + logged prompt saved in the portfolio folder.

> 🛡️ **Safety & copyright moment:** Why not upload a selfie? Your face is personal data and an avatar should protect you online. Why not "make me Spider-Man"? Characters are owned by companies — we create originals.

## 5. Share-out — Guild Hall reveal (10 min)
Slideshow of avatars with nicknames (students opt in). Announce Duel winners, update the house leaderboard, award badges live with the tracker. Preview Module 1: *"A startup has hired the Guild to build its brand…"*

## 6. Exit ticket (5 min)
1. Which prompt change helped your house most today, and why?
2. Rate your prompting skill 1–5. What will you practise next?
3. One thing you're excited to create this year.

## Differentiation
- **Support:** house roles (Prompt Writer, Checker, Logger, Speaker) so everyone contributes; avatar prompt template with blanks.
- **Extension:** Level-up — write a "system prompt" that turns the chatbot into a vocabulary quiz-master for Module 0; test it on a classmate and improve it twice (+50 XP).
