## Lesson objectives
Students will be able to…
- Explain that a chatbot writes by predicting the next **token**.
- Write a prompt using all five parts of the **Prompt Recipe**.
- Improve a prompt through at least three **iterations** and record why each change helped.

## Vocabulary today
prompt · token · prediction · iteration · context · constraint

---

## 1. Warm-up — "Be the autocomplete" (10 min)
Recall Raid (mini-whiteboards, houses): *"What is training data?"* / *"Why did our model break last lesson?"*
Then the autocomplete game: show half-sentences and houses write the most likely next word:
- "Once upon a…" → time
- "Peanut butter and…" → jelly
- "The capital of France is…" → Paris
- "My favourite colour is…" → (lots of answers!)

```teacher
You just acted like a language model. When there's one obvious next word, you all agreed. When there were many possibilities, you all guessed differently. That's exactly why AI needs detailed prompts — details narrow down the predictions.
```

## 2. Mini-lesson — Tokens and the Prompt Recipe (15 min)
1. **Tokens (3 min):** show **Visual 1**. AI reads text in small chunks (tokens) and predicts the next one, over and over. It doesn't plan the whole answer like you do.
2. **The Guild Prompt Recipe (7 min)** — show **Visual 2**:

| Part | Question it answers | Example |
|---|---|---|
| **Role** | Who should the AI act as? | "You are a friendly science teacher…" |
| **Task** | What exactly should it do? | "…explain how volcanoes erupt…" |
| **Details** | What must it include / avoid? (context + constraints) | "…mention magma and pressure, no more than 5 sentences…" |
| **Style** | What should it sound/look like? | "…fun, for 12-year-olds, with one joke…" |
| **Format** | What shape is the answer? | "…as a numbered list, then a 1-question quiz." |

3. **Worked example (5 min)** — live on the projector, improve a prompt and show each output:
   - v1: "volcanoes" → long, boring encyclopedia text.
   - v2: + Task: "explain how volcanoes erupt" → better but too long.
   - v3: + Details + Style: "in 5 sentences, for 12-year-olds, with one joke" → great.
   - v4: + Format: "as a numbered list, then a 1-question quiz" → ready to use.

## 3. Hands-on build — The Prompt Ladder (35 min)
Each student picks a mission card (or invents one):
- 🍕 A recipe for a snack you can make without an oven, for 4 people, no nuts.
- 📚 A study guide on any topic you're learning this week.
- 🎮 Rules for a new playground game that needs only a ball.
- 🐉 A short story opening about a dragon who's afraid of the dark.

Steps — fill in the **Prompt Log** for every version:

| Version | My prompt | What I got | What I'll change and WHY |
|---|---|---|---|
| v1 | (one line, no recipe) | | |
| v2 | + Role & Task | | |
| v3 | + Details & Style | | |
| v4 | + Format | | |

**Checkpoint 1 (+20 XP):** v1–v3 logged with reasons.
**Checkpoint 2 (+20 XP):** v4 done AND you checked one fact in the answer (is the recipe safe? is the study guide correct?).

Teacher-led variation (no student AI accounts): students write v1–v4 on paper; teacher runs 4–5 students' prompts on the projector while the class predicts the result first.

> 🛡️ **Privacy moment:** The Details part is where people overshare. Never put your full name, school, address or anything private into a prompt. Use "a 12-year-old student" instead of your name.

## 4. Game / challenge — Prompt Telephone (15 min)
Show a **mystery output** (e.g. a haiku about a sleepy cat in a list format with an emoji per line). Houses have 4 minutes to write the prompt that would produce it. Teacher runs each house's prompt live; the class votes which output is closest.
- Winning house +15 XP each; every house that uses all 5 recipe parts +5 XP.
- Run 2–3 rounds with harder outputs (a table, a tone of voice, a word limit).

## 5. Share-out — Prompt glow-up gallery (10 min)
Students paste their v1 and v4 side by side. Gallery walk with sticky notes: *I like… / I wonder… / Try…*. Teacher picks the **Prompt of the Week** candidate.

## 6. Exit ticket (5 min)
1. Name the 5 parts of the Prompt Recipe (from memory!).
2. Why does adding details give better results? (Use *predict* or *token*.)
3. Rewrite this weak prompt: "write about dogs".

## Differentiation
- **Support:** Prompt Recipe card with sentence starters ("You are a… / Please… / Include… / Make it sound… / Give it to me as…"); start from a half-filled v2.
- **Extension:** add an **example** to the prompt ("Here's one I like: …") and compare; try "ask me 3 questions before you answer" and explain why it improves results.
