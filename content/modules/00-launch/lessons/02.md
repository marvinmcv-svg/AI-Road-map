## Lesson objectives
By the end, the student can…
- Say that a chatbot writes by guessing the next **token** (a small piece of a word).
- Write a prompt with all 5 parts of the **Prompt Recipe**.
- Make a prompt better 3 times, and say why each change helped.

## Words for today
- **Prompt** — what you type to tell the AI what you want.
- **Token** — a small chunk of text, like a piece of a word. AI reads and writes in tokens.
- **Prediction** — the AI's best guess for the next token.
- **Iteration** — trying again with a small change to make it better.
- **Details** — extra facts that help the AI (who it's for, how long, what to skip).

## 1. Warm-up — "Be the autocomplete" (10 min · 1-on-1: 5 min)
Quick recall: *"What is training data?"* and *"Why did our AI get tricked last time?"*

Then play autocomplete. Read half a sentence. The student writes the next word:
- "Once upon a…" → time
- "Peanut butter and…" → jelly
- "The capital of France is…" → Paris
- "My favorite color is…" → (lots of answers!)

```teacher
You just acted like an AI chatbot. When there was one easy next word, you got it fast. When there were lots of choices, the answers were all over the place. That's why AI needs details. Details help it pick the right next word.
```

```group
Houses answer on whiteboards. Count how many houses gave the same word.
```

```solo
Take turns. You read one, the student answers. Then the student makes up half-sentences for you. Ask: "Which ones were easy to guess? Why?"
```

## 2. Mini-lesson — Tokens and the Prompt Recipe (15 min · 1-on-1: 10 min)
1. **Tokens:** show **Visual 1**. The AI reads text in small chunks. It guesses the next chunk, then the next, then the next. It does not plan the whole answer like you do.
2. **The Guild Prompt Recipe:** show **Visual 2**.

| Part | Question it answers | Example |
|---|---|---|
| **Role** | Who should the AI act like? | "You are a friendly science teacher…" |
| **Task** | What should it do? | "…explain how volcanoes erupt…" |
| **Details** | What must it have or skip? | "…talk about magma, use 5 sentences or less…" |
| **Style** | How should it sound? | "…fun, for a 10-year-old, with one joke…" |
| **Format** | What shape is the answer? | "…as a numbered list, then a 1-question quiz." |

3. **Show it live in Gemini.** Run each prompt and look at the answer:
   - v1: "volcanoes" → a long, boring answer.
   - v2: add the Task: "explain how volcanoes erupt" → better, but too long.
   - v3: add Details and Style: "in 5 sentences, for a 10-year-old, with one joke" → great.
   - v4: add Format: "as a numbered list, then a 1-question quiz" → ready to use.

```solo
Let the student guess what Gemini will say before you press Enter each time. Ask: "Which part made the biggest change?"
```

## 3. Hands-on build — The Prompt Ladder (35 min · 1-on-1: 25 min)
The student picks a mission card (or makes one up):
- 🍕 A snack recipe with no oven, for 4 people, no nuts.
- 📚 A study guide on something they're learning this week.
- 🎮 Rules for a new playground game that needs just a ball.
- 🐉 The start of a story about a dragon who is scared of the dark.

Climb the ladder in **Gemini**. Fill in the **Prompt Log** each time:

| Try | My prompt | What I got | What I'll change and WHY |
|---|---|---|---|
| v1 | (one line, no recipe) | | |
| v2 | + Role & Task | | |
| v3 | + Details & Style | | |
| v4 | + Format | | |

**Checkpoint 1 (+20 XP):** v1 to v3 written down with reasons.
**Checkpoint 2 (+20 XP):** v4 done, AND one fact in the answer was checked. (Is the recipe safe? Is the study guide right?)

```group
Everyone works on their own card. Walk around and ask: "What will you add next, and why?"
```

```solo
Sit side by side. The student types. You only ask questions: "Who is this for?" "How long should it be?" "What shape do you want?" If time is short, stop at v3 and do v4 for homework.
```

No Gemini for the student? They write v1 to v4 on paper. You type them into Gemini on your screen. Guess the answer together first.

> 🛡️ **Privacy moment:** The Details part is where people share too much. Never put your full name, school, address or anything private in a prompt. Say "a 10-year-old student" instead of your name.

## 4. Game / challenge — Prompt Telephone (15 min · 1-on-1: 10 min)
Show a **mystery answer** you made in Gemini. For example: a short poem about a sleepy cat, as a list, with an emoji on every line. Write the prompt that would make it. Run it in Gemini. Which answer is closest?
Do 2 or 3 rounds. Make them harder each time (a table, a voice, a word limit).

```group
Houses get 4 minutes per round. Run each house's prompt live. The class votes for the closest. Winning house +15 XP each. Every house that uses all 5 recipe parts +5 XP.
```

```solo
**You vs. Bolt.** You both write a prompt for the same mystery answer. Run both in Gemini. The student judges which is closer, and must say why. Then switch: the student makes a mystery answer for YOU to match. 15 XP for playing, +5 for using all 5 parts.
```

## 5. Share-out — Prompt glow-up (10 min · 1-on-1: 5 min)
Put the v1 and v4 answers side by side. Talk about them with: *I like… / I wonder… / Try…*
Pick a **Prompt of the Week**.

```group
Gallery walk with sticky notes.
```

```solo
The student reads v1 and v4 out loud and tells you the best change they made. You give one "I like" and one "Try". Save v4 as their Prompt of the Week.
```

## 6. Exit ticket (5 min)
1. Name the 5 parts of the Prompt Recipe (from memory!).
2. Why do details give better answers? Use the word *guess* or *token*.
3. Make this weak prompt better: "write about dogs".

```solo
Do it out loud. For question 3, let the student type it into Gemini and see if it worked.
```

## Differentiation
- **Extra help:** give the Recipe card with the parts already labeled. Do the ladder together for v1 and v2, then let them try v3 alone.
- **Extra challenge:** add a rule to the prompt ("don't use the letter e", "exactly 50 words"). Does Gemini follow it? Check by counting.
- **1-on-1 tip:** use the student's own hobby for the mission card. They will care more about the answer.
