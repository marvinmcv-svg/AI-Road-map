## 🔥 Warm-up
**Be the autocomplete!** Write the next word: "Once upon a…", "Peanut butter and…", "My favorite color is…". Which ones were easy to guess? Which ones weren't?

## 💡 Big idea
AI writes one small piece at a time. Each piece is called a **token**. It guesses what comes next, again and again. **Details help it guess better.** Use the Guild Prompt Recipe:

| Part | Ask yourself |
|---|---|
| 🎭 **Role** | Who should the AI act like? |
| 🎯 **Task** | What should it do? |
| 🔍 **Details** | What must it have? What should it skip? |
| 🖌️ **Style** | How should it sound? |
| 📐 **Format** | What shape is the answer? (list, table, poem…) |

```try
You are a friendly science teacher. Explain how volcanoes erupt. Talk about magma and pressure. Use 5 sentences or less, for a busy college student, with one joke. Give it as a numbered list, then a 1-question quiz.
```

## 🛠️ Your build: the Prompt Ladder
Pick a mission card: snack recipe 🍕, study guide 📚, playground game 🎮 or dragon story 🐉. Use **Gemini**.
- [ ] Try 1: write a one-line prompt. Save the answer.
- [ ] Try 2: add **Role + Task**
- [ ] Try 3: add **Details + Style**
- [ ] Try 4: add **Format**
- [ ] For each try, write what you changed and **why**
- [ ] Check one fact in your last answer. Is it true? Is it safe?

## ⚔️ Challenge: Prompt Telephone
Your teacher shows a mystery answer from Gemini. Write the prompt that made it. Closest match wins!

```group
Your house has 4 minutes to write the prompt.
```

```solo
**You vs. your teacher.** You both write a prompt for the same mystery answer. You judge whose is closer. Then make a mystery answer for your teacher to match!
```

## 🎟️ Exit ticket
1. Name the 5 parts of the Prompt Recipe. From memory!
2. Why do details give better answers?
3. Fix this weak prompt: "write about dogs".

## 🛡️ Stay safe
Never put your full name, school, address or passwords in a prompt. Say "a college student" instead of your name.
