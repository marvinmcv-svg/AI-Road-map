## 🔥 Warm-up: What would AI add?
A tutor that quizzes you? A coach that looks at your week? A one-line summary? Pick the idea that helps your user most.

## 💡 Big idea: where the key lives
**App → your Vercel function (holds the key) → Claude API → answer back to the app.**

Never call Claude straight from the app. Anyone could steal the key!

**5 safety rules:**
1. 🔑 Key only in Vercel environment variables
2. 🙋 Only logged-in users
3. 🔢 A daily limit and a max message length
4. 📜 A clear system prompt
5. 💳 A low spending limit in the Claude Console

```try
Add an AI feature to my app: a coach that looks at my last 7 days of water logs and gives one friendly tip. Use a Vercel server function that calls the Claude API with model claude-opus-5-5. Read the key from the ANTHROPIC_API_KEY environment variable. Only answer logged-in users. Limit each user to 20 requests a day. Show a loading message and a friendly error. Explain each part simply.
```

## 🛡️ Stay safe
Your app's AI must never act like a doctor or therapist. It should suggest talking to a trusted person or a professional.
