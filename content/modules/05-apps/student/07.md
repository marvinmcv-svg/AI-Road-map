## 🔥 Warm-up: Lost phone
If you lose your phone, where is your app's data? Open your app on a laptop. Is your data there?

## 💡 Big idea: cloud + login + privacy
- ☁️ **Supabase** — a free cloud database with login built in
- 🔑 **Login** — the app knows which data is yours
- 🔒 **Row Level Security (RLS)** — each person sees only their own rows

**Two keys:**
- 🔵 **Public key** — OK in the app, ONLY with RLS on
- 🔴 **Secret key** — NEVER in the app, repo, chat or screenshot

```try
Connect my app to Supabase. The project URL and public key will be in environment variables. My table is [name] with columns [list], including user_id. Add sign-up, log-in and log-out. Save and load data from Supabase, only for the logged-in user. Tell me the exact Row Level Security rules to add so users can only see and change their own rows. Never put the secret key in the code.
```
