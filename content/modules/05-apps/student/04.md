## 🔥 Warm-up: Ready to build?
Read your user stories out loud. Does every story have a screen?

## 💡 Big idea: from plan to phone
1. 📁 **GitHub** — a new repo for your app
2. 🤖 **Claude Code** — give it your build prompt, screens, icon and design
3. ✅ **Check** — try every user story
4. 🚀 **Vercel** — deploy and get a link
5. 📲 **Install** — iPhone: Safari → Share → Add to Home Screen. Android: Chrome → Install app.

```try
Build version 1 of my mobile app as an installable web app (PWA) with plain HTML, CSS and JavaScript. App name: Water Streak. Icon: icon.png. User stories: [paste]. Screens: Home, Add, History, Settings, with a bottom tab bar. Use fake sample data for now. Add a manifest so it can be added to a phone's home screen. Thumb zone, big tap targets, feedback after every tap. Explain what you built in simple words.
```

## 🛠️ Your build
- [ ] Make a GitHub repo and open it in Claude Code
- [ ] Add your icon and screen photos, paste the build prompt
- [ ] Test every user story and ask for fixes
- [ ] Deploy on Vercel
- [ ] Install the app on your phone
- [ ] Open it from your home screen!

## ⚔️ Challenge: Story Check
Read each user story to a tester. Can they do it in 3 taps or fewer?

```group
Swap phones with another house.
```

```solo
**You vs. your teacher.** Do the stories on each other's apps. Count the taps!
```

## 🎟️ Exit ticket
1. What do Claude Code, GitHub and Vercel each do?
2. How do you add a web app to a home screen?
3. Which user story works best so far?
