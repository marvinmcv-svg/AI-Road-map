## 🔥 Warm-up: Bug safari
Find all 3 bugs in your teacher's buggy app in 5 minutes!

## 💡 Big idea: the debugging loop
1. 🔁 **Repeat it** — write the exact steps
2. 🔎 **Look** — open the Console. Any red error? Copy it.
3. 📝 **Report** — steps · what you expected · what happened · the error
4. 🔧 **Fix and re-test** — test the bug AND the things around it

**Save points:** every change is a **commit**. If a change breaks your app, ask Claude Code to undo it.

```try
Steps: open Add, leave Amount empty, tap Save. Expected: a message "Please add an amount". Actual: the app shows a blank screen. Console error: [paste]. Please fix it and explain the cause simply.
```
