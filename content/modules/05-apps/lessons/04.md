## Lesson objectives
By the end, the student can…
- Ask Claude Code to build version 1 of their app from user stories, screens and a style guide.
- Put it online with Vercel.
- Install it on a phone's home screen, so it opens like a real app.

## Words for today
- **Version 1** — the first working build. Not perfect, just working.
- **Installable web app (PWA)** — a web app with an icon and a name, so you can add it to your home screen.
- **Manifest** — a small file that tells the phone the app's name, icon and colors.
- **Repo** (again) — the app's folder on GitHub, with every change saved.
- **Deploy** (again) — putting it online. Vercel does it every time the repo changes.

## 1. Warm-up — Ready to build? (10 min · 1-on-1: 5 min)
Read your user stories out loud. Show your screens and style guide. Anything to change before you build?

```solo
The student reads the stories; you point to the matching screen for each. Any story without a screen gets fixed now.
```

## 2. Mini-lesson — From plan to phone (10 min · 1-on-1: 7 min)
Show **Visual 1**:
1. **GitHub:** a new repo for the app (like `water-streak`).
2. **Claude Code:** give it the build prompt (below), your screen photos, the icon and the design link.
3. **Check:** try each user story. Ask for fixes, one at a time.
4. **Vercel:** import the repo → deploy → you get a link.
5. **Install:** open the link on your phone → **Add to Home Screen** (iPhone, in Safari) or **Install app** (Android, in Chrome).

**The build prompt:**
```
Build version 1 of my mobile app as an installable web app (PWA) with plain HTML, CSS and JavaScript.
App name: [name]. Icon: icon.png. Style guide: [colors, font, button style].
User stories: [paste 3 to 5 stories]. Screens: [list them]. A bottom tab bar with icons and words.
For now, use fake sample data (we'll save real data next lesson).
Add a manifest and what's needed so it can be added to a phone's home screen and opens full screen.
Follow these rules: thumb zone, big tap targets, feedback after every tap.
Explain what you built in simple words, and tell me how to test it.
```

## 3. Hands-on build — Version 1 (45 min · 1-on-1: 31 min)
1. Make the GitHub repo and open it in Claude Code.
2. Add your icon and screen photos, and paste the build prompt.
3. Test every user story. Write fixes as clear requests: "On the Add screen, make the Save button full width and move it to the bottom."
4. Import the repo in Vercel and deploy.
5. Install the app on your phone. Open it from the home screen.

**Checkpoint 1 (+20 XP):** every screen and the tab bar work in the preview.
**Checkpoint 2 (+20 XP):** app is live on Vercel and installed on a phone.

```group
Walk around and ask: "Which user story are you testing right now?"
```

```solo
Let the student drive Claude Code. You hold the plan and tick off stories as they work. When it's on the home screen, take a photo of the moment!
```

> 🛡️ **Repo moment:** nothing private goes into the repo: no real names, passwords or keys. Fake sample data only.

## 4. Game / challenge — Story Check (10 min · 1-on-1: 7 min)
Read each user story to a tester. Can they do it in the app in 3 taps or fewer, with no help?

```group
Swap phones with another house. Every story done in 3 taps: +3. Most points: +15 XP. Everyone: +5.
```

```solo
**Student vs. Bolt.** You do the stories on their app; they do the stories on your demo app. Count taps. +15 XP for playing, +5 if every story is 3 taps or fewer.
```

## 5. Share-out — Home screen reveal (10 min · 1-on-1: 5 min)
Show your app on your home screen next to your other apps. Open it like a real app.

```solo
Celebrate this one! Then ask: "What's the first thing you want to add?" Put it on the Later list.
```

## 6. Exit ticket (5 min)
1. What do Claude Code, GitHub and Vercel each do for your app?
2. How do you add a web app to a home screen?
3. Which user story works best so far?

```solo
Ask out loud. Next lesson, the app starts remembering real data.
```

## Differentiation
- **Extra help:** build the Home and Add screens first, deploy, install, then add the rest.
- **Extra challenge:** add a splash color and a short app name for the home screen, and make it work offline (ask Claude Code for a service worker and explain it).
- **1-on-1 tip:** if anything breaks, read the error out loud together and give it to Claude Code word for word. Don't fix it yourself.
